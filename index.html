Supernova OS is a free, open, and blindingly fast desktop built on the Pulsar UI toolkit. It detonates the old way of computing and leaves a brighter galaxy behind.

Synthesis in every layer

Pulsar UI

A hand-crafted C toolkit. Silky window management, native widgets, and zero bloat.

Singularity Security

Sandboxed apps, per-process isolation, and a hardened core that never collapses.

Nova Package Core

Atomic updates and instant rollbacks. Your system only ever moves forward.

Deep Space Theme

A GPU-accelerated dark interface tuned for long nights among the stars.

Instant Boot

From cold metal to login in under four seconds on modern hardware.
